# FUNN-AGENT
Use AI to: Solve math, fetch APIs, read encyclopedic data, create images, create code, create audio voice, and to chat!
**FUNN AGENT** allows users to load in API keys, from mainstream and from good free providers, to chat with lightweight to midweight models.
**FUNN AGENT** lets the bots fetch and search their information from Reitcyclopedia. This means that its info is enriched by contributors.
**FUNN AGENT** has built in Special Connectors. These are special connections and APIs that let you reach highly tailored use cases:
  - Razz Master Calculator: Allows simple to complex calculations and some conversions to be done by AIs to increase numerical precision.
  - Minecraft: Allows you to fetch Minecraft users' skins using user names and user IDs, and allow the AI to pose them if wanted.
  - Modrinth: Allows the fetching of Modrinth users and projects and details, for AI to see and for you to see, with useful cards.
**FUNN AGENT** has built in power modes, like standard, lean, and SuperLite, which each help to maximize token spending on the AI models.
**FUNN AGENT** has a canvas tool with supported previews of markdown, HTML, and more for the AIs to directly interface with and build.
**FUNN AGENT** lets users upload text based files like SVGs, HTML, and text files to the bots for them to read and improve anything.
**FUNN AGENT** has voice and image generators built in, allowing simple voice and images to be generated at ease if ever needed.
**FUNN AGENT** has a whole suite of UI quality features, and user quality features including:
  - Chat history with naming, deletion, and management, all on your device
  - Chat starring in history functioning like a pin
  - Chat searching with keyword lookups performed on your device
  - Chat markdown exporting for keeping and transporting
  - Stack feature letting AIs stack on each other to attempt a bigger task
  - Chat memory feature letting bots remember some info
  - Custom personas and instructions to guide the bot better
  - Easy API key management and adding interface supporting providers like:
    - Groq, OpenRouter, Pollinations, NVIDIA, and Google AI
  - Settings supports automatic model switching on limited rates
  - Article searching and auto reading can be disabled and tweaked
